# Obsidian-Tasks-Calendar

An Obsidian Dataview calendar based on [702573N/Obsidian-Tasks-Calendar](https://github.com/702573N/Obsidian-Tasks-Calendar), with task merging, status fixes, and faster rendering.

Install Dataview and open `task-calendar.md`. Keep it beside `view.js` and `view.css`.

Set `taskFolder` and `dailyNoteFolder` in the note. A leading `/` means the vault root; other paths are relative to the note. Set `mergeTasks: true` to combine duplicate entries and their icons. Dates use the device's local timezone automatically.
